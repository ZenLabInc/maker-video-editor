# 仕様 v0.1

## 会話で確定した要件

Osmo Pocketの手元映像をmicroSD経由で取り込み、Mac画面録画と共通時間軸で編集します。無言の画面操作や手元作業を削除せず原則4倍速にし、本人とPCの発話、その前後と短い間は通常速度にします。重要な非発話音を手動保護できます。Pythonが制御と計画、FFmpegが映像処理を担い、通常編集は生成AI APIや編集ソフトのコンピュータ操作に依存しません。計画JSONを修正し、解析なしで再レンダーできることが必要です。OP／EDを前後に追加し、プレビューで確認します。

## 提案として採用した設定可能な初期値

画面を大きく手元を右下小窓にする配置、手動で主副を交換する区間指定、倍速音声ミュート、発話前後0.3秒、短い間0.6秒、1920×1080／30fps、目標-16LUFSを初期値にします。値は仕様上の固定要件ではありません。現コードの小窓位置・比率と最終音量目標は実装定数で、それ以外は設定または計画から変更できます。

## 未確定事項

Osmoの撮影モード・fps・色設定、Macの画面録画方法と内部音声の実収録、両素材の共通音の有無、実際のオフセットと長時間ドリフト、OP／EDの支給素材、VADの実素材精度、YouTubeの認証プロジェクトと投稿メタデータ方針は未確認です。手動オフセットは必須機能で、0秒という初期値は同期済みの宣言ではありません。

## 初版の実装範囲と後続範囲

実装済みは2素材の共通区間、手動同期、energy解析、選択可能なSileroアダプター、通常／倍速区間計画、固定小窓と手動主副交換、両音声の合成、OP／ED、低解像度プレビュー、最終レンダー、投稿準備JSONです。Silero実モデル推論は未検証です。同期自動推定・ドリフト補正・意味画像解析・実YouTube投稿は未実装で、後続設計として扱います。

## 入力と前提

手元映像（Osmo Pocket／マイク音声）1本と、Mac画面録画（内部音声を含む想定）1本を扱います。コーデック、解像度、フレームレート、内部音声の収録方法は未確認です。FFmpegがデコードできる動画を入力とし、先頭の映像・音声ストリームを使います。音声なしは警告を出して無音として扱います。microSDの検出・自動コピー、複数分割ファイルの連結は未実装です。

## 時間軸

すべての指定区間は手元動画の先頭を0秒とする共通時間です。`screen_offset = +2` は、画面録画の先頭が手元の2秒に対応する意味です。共通時刻tに対する画面側の読み出し位置は `t - screen_offset` です。画面録画のほうが先に始まった場合は負数です。

初版は両映像が存在する共通区間 `[max(0,offset), min(hands_duration,offset+screen_duration)]` を編集します。共通区間外の素材は出力しません。この除外量は素材別の警告に記録します。共通区間がなければエラーです。欠落区間の黒画面埋めや片側だけの採用は将来拡張です。

各区間の出力尺は `(end-start)/speed` です。両映像に同じ速度を適用します。通常速度の両音声を同期して合成し、倍速区間は同じ出力尺の無音に置き換えます。許可速度は1、2、4、8倍です。短い区間はフレームの丸め誤差が生じます。

## 解析

既定 `silero` はローカルSilero VADによる発話区間です。両素材の検出結果を共通時間へ移して和集合を取ります。既定の前後余白は0.3秒、短い間の連結は0.6秒です。判定漏れはプレビューで確認し、重要な非発話音は `normal_ranges` に指定します。SileroはAPIを呼ばず、pipパッケージ同梱モデルを読み込みます。

明示選択 `energy` は16kHzモノラル100ms窓のRMSを既定-38dBFSで比較します。発話／工具音／音楽を識別しません。Sileroと同等ではありません。音量しきい値はenergyにのみ適用されます。Sileroはライブラリ既定の発話確率しきい値を使います。

## 設定

examples/config.jsonからの相対パスで素材を指定します。作成される計画には絶対パスを保存します。

| キー | 内容／既定 |
|---|---|
| hands / screen | 必須の素材ファイル |
| screen_offset | 画面録画の開始時刻、既定0秒 |
| analysis.method | silero（energyは明示選択） |
| analysis.padding / bridge_gap | 発話前後余白／短い間の保護、0.3／0.6秒 |
| normal_ranges | 重要音などを保護する `[start,end]` の配列 |
| hands_large_ranges | 手元を大きくする区間の配列 |
| silent_speed | 既定4倍 |
| gains | hands、screenそれぞれ0〜8の線形音量倍率 |
| opening / ending | 任意の動画、未指定はnull |
| output | width=1920、height=1080、fps=30 |

区間外の手動範囲は共通区間に切り詰めます。通常速度指定と手元拡大指定は独立しています。画角比を維持して黒帯で調整します。小窓は各辺がおおむね全体の1/3、右下12px余白です。サイズ・位置の自由指定は未実装です。

## 編集計画JSON

`version=1`、`sources`（path、offset）、`range`、`segments`、`output`、`opening`、`ending`、`warnings`、`analysis`を持ちます。segmentsの各要素はstart、end、speed、layout（screenまたはhands）、gainsを持ちます。区間は連続し、重複・欠落なくrange全体を覆う必要があります。区間を分割して速度や配置を変更できます。解析情報は生成時の記録で、レンダーはsegmentsを正として使います。

音量は区間ごとの線形倍率、合成時のピークリミッター、完成動画全体の一回処理loudnorm（目標-16LUFS、-1.5dBTP）です。放送規格への厳密適合や二回測定による音量一致は保証しません。オープニングとエンディングは速度を変えず前後に挿入します。
